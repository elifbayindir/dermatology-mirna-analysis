# Blog series

These five English drafts were prepared for [foolonthehillweb.com](https://foolonthehillweb.com/). Each post has its own figures and tables folder. The placement notes, image links, and final captions are included in the post files.

1. [Data Science - Medicine Application Project 1 Part 1](part-1/post.md) covers the synthetic study design, validation, cohort characteristics, and clinical profile.
2. [Data Science - Medicine Application Project 1 Part 2](part-2/post.md) covers ΔCq, reference checks, the primary comparison, and normalization sensitivity.
3. [Data Science - Medicine Application Project 1 Part 3](part-3/post.md) covers clinical correlations, multiple testing, and exploratory subgroup analysis.
4. [Data Science - Medicine Application Project 1 Part 4](part-4/post.md) covers adjusted logistic models, diagnostics, cross-validated ROC analysis, and paired AUC comparison.
5. [Data Science - Medicine Application Project 1 Part 5](part-5/post.md) covers sensitivity analysis, co-expression, and prospective power planning.

The [asset manifest](asset-manifest.csv) lists all ten figures and fourteen table images. Every post states that the dataset is synthetic and that the results have no clinical meaning.
