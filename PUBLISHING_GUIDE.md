# Publishing guide

This folder is ready to become a standalone GitHub repository. No remote repository has been created and nothing has been uploaded.

## Suggested repository name

`synthetic-dermatology-mirna-analysis`

## Before publishing

- Run the notebook from a clean environment.
- Confirm that every file under `data/` is synthetic.
- Search the repository for names, local paths, hospital terms, and original study IDs.
- Keep the synthetic-data warning near the top of the README and notebook.
- Do not add screenshots or tables from a real thesis.
- Do not describe simulated results as evidence about acne or miRNA biology.

## Suggested project card

**Synthetic Dermatology miRNA Analysis**

A public teaching version of a clinical qPCR workflow. The project uses generated data to demonstrate validation, ΔCq interpretation, reference stability, FDR control, adjusted association models, cross-validated ROC analysis, subgroup estimates, and sensitivity checks.

## Suggested CV line

Built a reproducible Python and Jupyter workflow for a synthetic dermatology miRNA case study, including data validation, ΔCq analysis, FDR control, adjusted models, cross-validated ROC curves, and normalization sensitivity checks.
